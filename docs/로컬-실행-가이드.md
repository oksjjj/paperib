# 로컬 실행 가이드

IB 시계열에 anomaly 라벨을 붙이거나 수정할 때는 **라벨링 앱**(Dash)을 사용합니다.

| | **라벨링 앱** |
|---|---|
| 용도 | anomaly 라벨 붙이기·수정 |
| 실행 | `python labeling/app.py` |
| URL | `http://127.0.0.1:8050/` |
| 데이터 | `data/` CSV + `labeling/cache/` |
| 라벨 저장 | `data/ib_data/labels/*_labels.json` |

---

## 공통 준비 (최초 1회)

저장소 루트에서:

```bash
cd /path/to/paperib
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```

원본 CSV는 `data/`에 둡니다 (`data/ib_data/raw/masked_YYYYMMDD.csv` 등).  
자세한 파일 배치는 [데이터-추가-가이드.md](데이터-추가-가이드.md)를 참고하세요.

---

## 라벨링 앱 열기

### ① 캐시 준비 (CSV 추가·변경 후)

```bash
cd /path/to/paperib
source .venv/bin/activate

python labeling/preprocess.py
```

- `data/*.csv` → `labeling/cache/{PLMN}.pkl` 생성
- `preprocess`는 기존 라벨 JSON을 **지우지 않습니다**

처음 clone 후 `data/`에 CSV가 없으면 캐시가 비어 있어 사업자 목록이 비거나 로드에 실패할 수 있습니다.

### ② 앱 실행

```bash
python labeling/app.py
```

- 자동으로 브라우저가 열립니다 → **http://127.0.0.1:8050/**
- 자동 실행이 안 되면 위 주소를 직접 입력
- 종료: 터미널에서 `Ctrl+C`

### ③ 기본 사용 흐름

1. 상단 **사업자** 드롭다운에서 PLMN 선택 (선택 즉시 차트 로드)
2. metric 필터로 보고 싶은 지표 선택
3. 클릭 모드로 라벨 추가:
   - **점 라벨** — 특정 시각에 anomaly/normal/uncertain 표시
   - **구간 라벨** — 시작·끝 두 번 클릭으로 구간 지정
4. 기존 라벨 선택 후 **구간 편집** 모드에서 경계 드래그로 수정
5. 라벨은 파일에 자동 저장 (`data/ib_data/labels/{PLMN}_labels.json`)

### OmniAnomaly 모델 오버레이 (선택)

```bash
pip install -r OmniAnomaly/requirements.txt
cd OmniAnomaly
../.venv/bin/python run_plmn.py --plmn P0480 --max_epoch 10 --stable_train
```

- 결과: `data/ib_data/predictions/P0480_omnianomaly.json`
- 라벨링 UI 상단 오버레이에서 **사람+모델** / **모델만** 선택 → 보라색 점선으로 표시
- 모델 예측은 사람 라벨과 별도 파일이며 편집·저장되지 않음
- 학습 곡선(TensorBoard, 기본 켜짐):

```bash
cd OmniAnomaly
../.venv/bin/python view_tensorboard.py --plmn P0480
# → http://127.0.0.1:6006/
```

- 자세한 내용: `OmniAnomaly/PAPERIB.md`
