# 로컬 실행 가이드

이 저장소에는 **두 종류의 웹 UI**가 있습니다.

| | **웹 뷰어** (읽기 전용) | **라벨링 앱** (편집) |
|---|---|---|
| 용도 | GitHub Pages와 같은 정적 뷰어로 결과 확인 | anomaly 라벨 붙이기·수정 |
| 실행 | `http.server` + `docs/viewer/` | `python labeling/app.py` (Dash) |
| URL | `http://127.0.0.1:8765/` | `http://127.0.0.1:8050/` |
| 데이터 | export된 JSON (`docs/viewer/data*`) | `data/` CSV + `labeling/cache/` |
| 라벨 저장 | ❌ (보기만) | ✅ `data/labels/*_labels.json` |

---

## 공통 준비 (최초 1회)

저장소 루트에서:

```bash
cd /path/to/paperib
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```

원본 CSV는 `data/`에 둡니다 (`data/masked_YYYYMMDD.csv` 등).  
자세한 파일 배치는 [데이터-추가-가이드.md](데이터-추가-가이드.md)를 참고하세요.

---

## 1) 웹 뷰어 열기 (읽기 전용)

GitHub Pages에 올라가는 것과 같은 **정적 뷰어**입니다. 라벨링 탭·Top 100 탭으로 시계열을 탐색합니다.

### ① export (JSON 갱신)

```bash
cd /path/to/paperib
source .venv/bin/activate

python labeling/export_viewer.py
```

- 기본값: **라벨링** (`docs/viewer/data/`) + **Top 100** (`docs/viewer/data-top100/`) 둘 다 export
- 라벨 PLMN이 없으면 라벨링 탭 export는 skip되고, Top 100은 export됩니다

이미 git에 export JSON이 있고 내용을 그대로 볼 거면 이 단계는 생략해도 됩니다.

### ② 로컬 서버 실행

```bash
cd docs/viewer
python -m http.server 8765
```

### ③ 브라우저에서 열기

| 주소 | 내용 |
|------|------|
| http://127.0.0.1:8765/ | 기본 — **라벨링** 탭 |
| http://127.0.0.1:8765/#top100 | **Top 100** 탭 |
| http://127.0.0.1:8765/#labeled | **라벨링** 탭 (명시) |

종료: 터미널에서 `Ctrl+C`

### 자주 겪는 상황

- **`data/index.json 없음`** — 라벨 export가 없음. **Top 100** 탭(`#top100`)으로 이동하거나 `export_viewer.py` 실행
- **`data-top100/index.json 없음`** — `python labeling/export_viewer.py --catalog top100` 실행
- **최신 라벨/데이터가 안 보임** — `export_viewer.py` 다시 실행 후 브라우저 새로고침 (강력 새로고침 권장)

## 2) 라벨링 앱 열기 (편집)

Dash 기반 **로컬 전용** 편집 UI입니다. 여기서 붙인 라벨은 `data/labels/*_labels.json`에 저장됩니다.

### ① 캐시 준비 (CSV 추가·변경 후)

```bash
cd /path/to/paperib
source .venv/bin/activate

python labeling/preprocess.py
```

- `data/*.csv` → `labeling/cache/{PLMN}.pkl` 생성
- `preprocess`는 기존 라벨 JSON을 **지우지 않습니다**

처음 clone 후 `data/`에 CSV가 없으면 캐시가 비어 있어 사업자 목록이 비거나 로드에 실패할 수 있습니다.

### ② 앱 실행

```bash
python labeling/app.py
```

- 자동으로 브라우저가 열립니다 → **http://127.0.0.1:8050/**
- 자동 실행이 안 되면 위 주소를 직접 입력
- 종료: 터미널에서 `Ctrl+C`

### ③ 기본 사용 흐름

1. 상단 **사업자** 드롭다운에서 PLMN 선택 (선택 즉시 차트 로드)
2. metric 필터로 보고 싶은 지표 선택
3. 클릭 모드로 라벨 추가:
   - **점 라벨** — 특정 시각에 anomaly/normal/uncertain 표시
   - **구간 라벨** — 시작·끝 두 번 클릭으로 구간 지정
4. 기존 라벨 선택 후 **구간 편집** 모드에서 경계 드래그로 수정
5. 라벨은 파일에 자동 저장 (`data/labels/{PLMN}_labels.json`)

### OmniAnomaly 모델 오버레이 (선택)

```bash
pip install -r OmniAnomaly/requirements.txt
cd OmniAnomaly
../.venv/bin/python run_plmn.py --plmn P0480 --max_epoch 10 --stable_train
```

- 결과: `data/predictions/P0480_omnianomaly.json`
- 라벨링 UI 상단 오버레이에서 **사람+모델** / **모델만** 선택 → 보라색 점선으로 표시
- 모델 예측은 사람 라벨과 별도 파일이며 편집·저장되지 않음
- 학습 곡선(TensorBoard, 기본 켜짐):

```bash
cd OmniAnomaly
../.venv/bin/python view_tensorboard.py --plmn P0480
# → http://127.0.0.1:6006/
```

- 자세한 내용: `OmniAnomaly/PAPERIB.md`

### 웹 뷰어에 반영하려면

라벨링 앱에서 저장한 내용을 공개 뷰어에 보이게 하려면 export 후 push:

```bash
python labeling/export_viewer.py --catalog labeled   # 또는 both
# git add / commit / push → docs/viewer/ 및 data/labels/
```

## 한눈에: 어떤 걸 쓰면 되나?

```text
데이터만 탐색·공유          →  export_viewer.py  →  http.server 8765  (뷰어)
라벨 붙이거나 수정          →  preprocess.py     →  app.py 8050       (편집)
라벨 수정 후 웹에 반영       →  export_viewer.py  →  git push
```
