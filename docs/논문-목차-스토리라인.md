# IB Inbound Roaming AD × 통신향 Argos — 목차 · 스토리라인 (초안)

참고 형식: 권예린, *5G/LTE 네트워크에서의 DBSCAN 클러스터링 기반 시그널링 공격 탐지* (고려대 석사, 2025)의  
**서론 → 관련연구 → 배경 → 제안 → 실험·분석 → 결론** 골격.  
내용 포지션: [논문-스토리라인.md](./논문-스토리라인.md), [baseline-참고논문.md](./baseline-참고논문.md).

> 상태: **목차·스토리 합의용** (2026-09-26).  
> 한 줄: DL 비지도 TSAD를 IB에 올리면 한계 → **준지도 multi-metric Argos**가 더 적합.

---

## 0. 간략 스토리라인 (서론→결론)

| 단계 | 내용 |
|------|------|
| **문제** | IB inbound roaming 제어면(5분) KPI로 운영 품질 이상을 탐지하고 싶다. 이상은 희소하고 mild~severe가 섞인다. |
| **도메인 제약** | GT는 통계 outlier가 아니라 rate/attempt/fail 등 **운영 의미**. 완전 지도는 라벨·미라벨 PLMN·설명 때문에 주장이 아님. |
| **기존 접근의 한계** | 대표 DL 비지도 TSAD(탐지 원리 3종)를 동일 프로토콜로 적용하면 mild **미탐**(재구성) 또는 residual **과탐**(예측) 등이 나타남. |
| **함의** | KPI 축이 분명한 IB에서는 블랙박스 다변량 점수보다 **설명 가능 규칙**이 맞다. |
| **제안** | 원본 Argos(단변량 LLM 규칙)를 IB에 맞게 **축별 규칙 + 융합(multi-metric)** 으로 조립한 통신향 Argos. |
| **검증** | 동일 분할·feature·평가로 baseline vs Argos 비교; primary는 label-free(비지도) / Argos는 준지도임을 명시. |
| **결론** | IB AD 설정·한계 분석·통신향 Argos의 적합성을 정리하고 한계·향후 과제를 남긴다. |

권예린 논문과의 **형식적 유사점**: 통신망 실데이터 · 도메인 절차 배경 · 제안 파이프라인 · 파라미터/설계 선택 근거 · 실환경 관점의 실험·분석.  
**내용적 차이**: 시그널링 DoS·DBSCAN·단말 단위가 아니라 **IB KPI 시계열 AD · DL TSAD 한계 · 준지도 Argos**.

## 2. 장별 스토리 (한 단락씩)

### 1장 서론
이동통신 **IB inbound roaming** 품질 모니터링에 TSAD를 쓰고 싶으나, 사람 GT는 KPI 운영 의미라 순수 통계 outlier와 다르다.  
대표 DL 비지도를 그대로 올리면 inductive bias가 GT와 어긋난다.  
완전 지도로 비약하지 않고, **설명 가능 준지도 규칙(Argos를 IB multi-metric으로 조립)** 을 제안한다.  
기여: (1) IB AD 설정·라벨, (2) DL 비지도 IB 한계 분석, (3) 통신향 Argos 제안·실증.

### 2장 관련 연구
TSAD를 **탐지 원리**로 정리하고 3픽 논문을 위치시킨다 (아키텍처 카테고리와 혼동 금지).  
지도/약지도 서베이로 “완전 지도가 답이 아닌 이유”를 문헌으로 받침.  
Argos(LLM→규칙, 배포 시 규칙만)와 통신망 선행(임계·클러스터링 등)을 구분하고,  
본 연구는 **IB KPI + multi-metric 융합**에서의 적합성을 다룬다고 차별화.

### 3장 배경·설정
IB 제어면 KPI, mild/severe, 라벨 원칙, 60/20/20, point+event.  
Argos `inference(value,index)` 계약과 train+valid export / valid 평가 매핑.

### 4장 제안
단변량을 **다변량 네트워크로 재작성**하지 않고,  
**축별 단변량 규칙 + 융합**으로 IB에 맞게 고도화.  
축·LLM/heuristic·fuse·설명·비지도와의 정보량 차이를 설계로 명시.

### 5장 실험·분석
동일 프로토콜로 3 baseline vs Argos.  
primary로 비교; best-F1은 상한 분석만.  
*왜*: 재구성 bias(mild 복원), 잔차 percentile(과탐), Argos는 KPI 축·라벨로 규칙 유도.  
Ablation으로 축/융합 기여를 분리.

### 6장 결론
한계(단일·소수 PLMN, LLM 비결정성, 준지도 정보량)와 향후(완화 액션, 다 PLMN, 축 자동 선택 등).

## 4. 작성 시 주의

- 표·본문에 **비지도 vs 준지도 정보량**을 항상 표기.
- 비교군 카테고리: Forecasting / Reconstruction / **Transformer** 혼용 금지 → **탐지 원리** 3축.
- 메인 지표는 **primary thr**; best-F1은 oracle 상한.
- “Argos 튜닝기”가 아니라 **IB 적합성·multi-metric 조립**이 기여의 전면.
